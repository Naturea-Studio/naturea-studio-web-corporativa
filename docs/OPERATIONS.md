# Operaciones
La ruta de desarrollo `/taller/operaciones` permite crear y editar lotes, calcular costes, filtrar el estado y exportar los resultados. Está disponible con `npm run dev` y queda fuera del enrutado de producción. Los datos de los ejercicios se mantienen en el navegador.

Pendiente para operaciones reales: autenticación y permisos en servidor, inventario transaccional, proveedores, auditoría de cambios, calendario de fabricación, pedidos y facturación. Las integraciones necesitan reglas de negocio y datos aprobados.
