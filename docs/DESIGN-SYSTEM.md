# Sistema de diseño

`src/styles.css` concentra tokens de papel, arena, texto, oliva, bordes, tipografía, espaciado y movimiento. Cormorant Garamond Variable se usa para titulares. Manrope Variable, para lectura e interfaz. Lucide aporta iconos funcionales.

Las imágenes ocupan el primer plano y los módulos editoriales alternan entre columnas y bloques divididos. En móvil cambian el orden y las proporciones de las imágenes. Los enlaces, botones, tarjetas y menús comparten transiciones cortas y foco visible. Las animaciones se reducen con la preferencia del sistema. Los menús son desplegables nativos desde botones y las notas de ayuda usan details/summary.
