# Referencias de mercado

| Referencia                                         | Observación y aplicación                                                                                                                                                    |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [HANNUN](https://hannun.com/)                      | Relaciona colecciones, ambientes, medidas y muestras de color. En Naturea los ambientes inspiran y las fichas detallan colección y material según datos validados.          |
| [Woodendot](https://woodendot.com/)                | Combina navegación por tipologías, colecciones y una entrada específica a medida. Naturea adopta esos recorridos paralelos, con composición editorial y fotográfica propia. |
| [Alemán Estudio](https://alemanestudio.com/)       | Presenta mesas de madera y epoxi con espesor y detalle comercial. La ficha Naturea reserva dimensiones y opciones para cuando se validen.                                   |
| [Piri Wood](https://piriwood.es/)                  | Combina mesas y bandejas de nogal con otros objetos de madera. Refuerza la idea de un catálogo que cubra distintas escalas.                                                 |
| [Mokuzai](https://mokuzai.es/arts-collection/)     | Agrupa mesas de epoxi bajo una colección diferenciada y ofrece ordenación por precio. Naturea acota la resina en River y conserva otros lenguajes materiales.               |
| [Moriche Atelier](https://www.moricheatelier.com/) | Organiza su trabajo en series y tipologías. En Naturea, colección y categoría se pueden explorar de forma independiente.                                                    |
| [Etsy](https://www.etsy.com/es/)                   | La recuperación por palabras y la personalización tienen entradas directas. Naturea incorpora un buscador acotado al catálogo conceptual propio.                            |

El acceso directo a [Maresinwood](https://maresinwood.com/) y [Ferm Living](https://www.ferm-living.com/) devolvió HTTP 502, [CunaCraft](https://cunacraft.es/) agotó el tiempo, [Kave Home](https://kavehome.com/) respondió HTTP 429 y [Audo](https://www.audocph.com/) quedó inaccesible desde la herramienta de consulta. El análisis se limita a las páginas que pudieron recuperarse.
