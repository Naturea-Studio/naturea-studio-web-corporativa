# Piezas únicas
La galería pública muestra estudios actuales y un archivo conceptual. Se puede guardar una selección en el dispositivo. La galería identifica las imágenes como referencias de diseño y mantiene cerradas las reservas.

Cada pieza física debe incorporar identificador, SKU, imágenes individuales, veta, medidas reales, peso y estado. La disponibilidad será unitaria. Las reservas reales requieren una transacción de base de datos con expiración y un control exclusivo sobre la unidad. Los estados reservado, vendido y archivado necesitan una fuente de inventario real antes de activar el flujo comercial.
